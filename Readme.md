# Polymorphism Practice - 1

## Question

Create the following classes:

- Dog
- Cat
- Cow

Each class should have a `speak()` method that prints its own sound.

Store all objects in a list and use a single loop to call the `speak()` method for every object.

**Rules:**
- Use classes and objects.
- Same method name in every class.
- No `if`, `elif`, `match-case`, `type()`, or `isinstance()`.

# Polymorphism Practice - 2

## Question

Create the following classes:

- Circle
- Square
- Rectangle

Each class should have an `area()` method that calculates and returns its own area.

Create one object of each class, store them in a list, and use a single loop to print the area of every shape.


**Rules:**
- Same method name in every class.
- Use polymorphism.
- No `if`, `elif`, `match-case`, `type()`, or `isinstance()`.
